# EliteTech Intern — Full Stack Developer Tasks

This repository contains implementations for all four tasks in the supplied EliteTech Intern Full Stack Developer assignment.

## Assignment coverage

1. **API Integration** — responsive weather webpage using the public Open-Meteo API.
2. **Chat Application** — real-time chat using Node.js + Socket.IO.
3. **Real-Time Collaborative Document Editor** — React UI + Node.js/Socket.IO backend + MongoDB persistence.
4. **Chrome Extension for Time Tracking and Productivity Analytics** — Manifest V3 extension + Node.js/Express backend + MongoDB persistence + analytics dashboard.

The assignment asks interns to store work-related code/files in GitHub and maintain proper code comments. Each task therefore has its own README, commented source, and run instructions.

## Prerequisites

- Node.js 18+
- npm
- MongoDB 6+ (local or MongoDB Atlas) for Tasks 3 and 4
- Google Chrome for Task 4

## Quick start

Open each task folder and follow its README. Tasks are intentionally separated so they can be submitted independently while also living in one GitHub repository.
