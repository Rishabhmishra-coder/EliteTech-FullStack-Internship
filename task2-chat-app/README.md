# Task 2 — Real-Time Chat Application

## Requirement

Develop a real-time chat application using WebSocket or Socket.IO, with frontend and backend integration.

## Stack

- Node.js
- Express
- Socket.IO
- Vanilla HTML/CSS/JavaScript frontend

## Features

- User name selection.
- Live messages delivered to all connected clients.
- Online user count.
- Join/leave system messages.
- Typing indicator.
- Message timestamps.
- Responsive UI.

## Run

```bash
npm install
npm start
```

Open `http://localhost:3002` in two browser tabs to test real-time communication.
